# Market Harmony Roadmap

Spec: `docs/superpowers/specs/2026-10-13-market-harmony-design.md`. Each plan ends at a gate. A gate result is a **stop-and-report checkpoint with Andy**, pass or fail. Plans 2–4 are provisional: each starts by re-reading the previous gate's results and updating its defaults (committed) before any code.

| # | Plan | Builds | Ends at | Needs |
|---|---|---|---|---|
| 1 | [listener-and-rhythm](2026-10-13-listener-and-rhythm.md) | features, onsets, tempo, beats, meter, the self-supervised listener, clock-only twin, surrogate | **Rhythm gate** | — |
| 2 | [harmony](2026-10-13-harmony.md) | measures, candidate keys with confidences, learned chord vocabulary, behavioral names (I–VII, V/x chains, deceptive), per-key readings | **Vocabulary + Harmony gates** | 1 passed |
| 3 | [cadence-and-backtest](2026-10-13-cadence-and-backtest.md) | destination labels (relative keys, detours allowed), CadenceNet, level-target backtester, walk-forward, holdout script | **Cadence gate → Backtest gate → Holdout (once)** | 2 passed |
| 4 | [live-paper-trading](2026-10-13-live-paper-trading.md) | rolling live state, parity check, dry-run loop; then bracket orders, recovery, paper report | **Dry-run parity → 2–3 months paper evaluation** | Tasks 1–3: Cadence gate passed. Tasks 4–6: holdout PASS + Andy's go |

## Where the data is touched

- **< 2021:** fitting (listener, vocabulary, names, CadenceNet train).
- **2021–2022:** validation and all selection.
- **2023:** first loaded in plan 3 (Cadence gate, last walk-forward fold).
- **2024+:** only `cadence_final.py --final`, once.

## If a gate fails

Stop. Log the result verbatim in `docs/experiments.md`, report to Andy, and do not silently fall back (e.g. no swapping in clock-time beats). Known pre-planned branch: if the Rhythm gate shows beats ≤ 2 bars apart, fetch 5m bars (IBKR, back to 2010) and re-run plan 1's gate before plan 2.
